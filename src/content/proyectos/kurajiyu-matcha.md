## El proyecto

Kurajiyu Matcha es una landing page desarrollada para presentar una marca de matcha y facilitar el contacto con potenciales clientes.

El objetivo principal fue crear una experiencia visual atractiva que transmitiera la identidad del producto y dirigiera al usuario hacia la acción de contacto.

## Objetivo

El proyecto buscaba principalmente:

- Presentar el producto de forma atractiva.
- Comunicar la propuesta de valor de la marca.
- Facilitar el contacto con clientes potenciales.
- Crear una experiencia adaptada a dispositivos móviles.

## Solución

Se desarrolló una landing page enfocada en conversión, utilizando una estructura clara y jerarquizada.

La página utiliza diferentes secciones para presentar el producto, comunicar sus beneficios y dirigir al usuario hacia los puntos de contacto.

## Tecnologías

El proyecto fue desarrollado utilizando:

- HTML
- CSS
- JavaScript
